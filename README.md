# Stacks Donation DApp

A simple on-chain donation tracker DApp on Stacks blockchain.

## Repository Structure


## Contract

- `donation.clar` — donation tracking contract
- Public functions:
  - `donate(amount)` → make a donation
  - `get-donation(donor)` → check donor donation
  - `get-total-donated()` → total donations

## Frontend

- Uses `@stacks/connect` for wallet connection
- Uses `@stacks/transactions` to call contract functions
- UI allows inputting donation amount and sending on-chain
